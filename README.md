# مساحة الكتابة (Writing Workspace)

تطبيق ملاحظات وكتابة يعمل دون إنترنت: مستندات وفصول طويلة، وسائط، نسخ احتياطي مشفّر، وبحث عربي.
كل البيانات تبقى على جهازك (IndexedDB) ولا تُرسل إلى أي خادم.

## الملفات
- `www/index.html`: التطبيق كاملاً (ملف واحد).
- `www/sw.js` و`www/manifest.webmanifest`: لتثبيته كتطبيق ويب (PWA) والعمل دون اتصال.
- `.github/workflows/android-apk.yml`: يبني ملف APK تلقائياً (Capacitor).
- `.github/workflows/pages.yml`: ينشر النسخة على GitHub Pages.

## الحصول على APK
1. أنشئ مستودعاً على GitHub وارفع محتويات هذا المجلد (Add file ← Upload files، أو `git push`).
2. افتح تبويب **Actions** ← **Build Android APK**. يعمل تلقائياً عند كل رفع، أو اضغط **Run workflow**.
3. بعد نحو 5–10 دقائق افتح التشغيل الناجح ونزّل **writing-workspace-apk** من قسم Artifacts. هو ملف `app-debug.apk`.
4. انقله إلى هاتفك وافتحه (فعّل «تثبيت من مصادر غير معروفة»).

ملاحظات:
- هذا APK تجريبي (debug) موقَّع بمفتاح التطوير، ويصلح للاستخدام الشخصي. للنشر على Google Play تحتاج توقيعاً بمفتاحك (release).
- غيّر `appId` في `capacitor.config.json` (الحالي `com.example.writingworkspace`) إلى معرّف خاص بك قبل أول تثبيت، فتغييره لاحقاً يعني تطبيقاً جديداً ببيانات جديدة.
- بيانات التطبيق داخل مخزن التطبيق على الهاتف. حذف التطبيق أو مسح بياناته يحذف المكتبة، فخذ نسخة احتياطية (💾) دورياً. الحفظ على الأندرويد يفتح نافذة المشاركة لاختيار «حفظ في الملفات».
- لم يُختبر البناء ولا التطبيق على جهاز أندرويد حقيقي قبل تسليم هذا المجلد.

## النسخة كموقع (PWA)
فعّل GitHub Pages: Settings ← Pages ← Source: **GitHub Actions**، ثم ادفع إلى فرع `main`. افتح الرابط من الهاتف واختر «إضافة إلى الشاشة الرئيسية».
لتحديث النسخة المخزنة بعد تعديل التطبيق ارفع رقم `V` في `www/sw.js`.
